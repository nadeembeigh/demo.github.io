# Dr. Nadeem Tariq Beigh — Static Academic Website

This package is built with plain HTML and CSS. It has no framework, dependency,
installation command, or build step.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload everything inside this folder to the repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **GitHub Actions**.
5. Push to the `main` branch. The included workflow publishes the website.

## Edit the website

- Page content and links: `index.html`
- Colors, typography and layout: `styles.css`
- Portrait, research montage and favicon: `assets/`

The website can also be opened locally by double-clicking `index.html`.
